# Slicer_Configuration — Profils OrcaSlicer Namma

Ce dépôt contient les profils **OrcaSlicer** des imprimantes 3D **Namma** (gammes ANA, Lucy et EVA) : machines, profils d'impression et filaments Namma.

> Les profils sont testés avec **OrcaSlicer 2.4.2**. Il faut au minimum la version **2.4.1** ([téléchargement d'OrcaSlicer](https://github.com/SoftFever/OrcaSlicer/releases)).
> Ils remplacent les anciens profils **Namma Slicer**, qui ne sont plus maintenus.

## Machines et filaments

| Gamme | Modèles | Buses |
|---|---|---|
| ANA | ANA 300, ANA 300 V2, ANA 300 HT, ANA 300G (tête 2 à granulés), ANA 600 | 0.4 / 0.6 / 0.8 (+ 1.0 sur ANA 600) |
| Lucy | Lucy 300 | 0.4 / 0.6 / 0.8 |
| EVA | EVA 500 et EVA 1000, têtes 3DF05, 3DF09 et 3DP25 (granulés) | 0.4 / 0.6 / 0.8 (3DF05), 1.2 / 2.5 (3DF09), 3.0 (3DP25) |

Matières disponibles : PLA, PLX, ABS, ABS-INDUS, ASA, PETG, PETG-CF, PETG-GF, PETG-GF UV, PETG-ESD, PC, TPU, PAHT CF, PPA CF, PPS CF, PEEK, PEI, BVOH, PVA, Soluble 90 / 111 / 150, EASY FOOD, EASY V0 et Granulé.

## Installation

Téléchargez la dernière version depuis la page **[Releases](https://github.com/tomlop33/Slicer_Configuration/releases)** du dépôt : le bundle et toutes les instructions d'installation et de mise à jour s'y trouvent.
